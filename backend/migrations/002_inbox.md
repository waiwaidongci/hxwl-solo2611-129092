# 002 站内收件箱当前版

应用启动时由 SQLAlchemy 自动补建，无需手工迁移。

- `inbox` 每个营业日一行，记录该日站内收件箱的当前版：`base_run_id` 为首次投递的初版运行（补发沿用其排班与门槛），`run_id` 与 `cutoff` 为当前版运行及其截点，`recipient` 为收件团队，`published_at` 为最近切换时间。切换在同一事务内完成，且仅当新截点晚于当前截点时才覆盖，因此并发补发中较早截点的结果不会盖掉已发的较晚版；被拦截或失败的补发不改动该表，旧版保留。

补发本身复用 `runs`（`params.reissue=true`，`params.batch_ids` 在后台首次认领时固定，供中断重试沿用）与 `deliveries`（每个运行最多一个回执，`state` 新增 `superseded` 表示结果已被更晚截点的版本压在历史版）。
